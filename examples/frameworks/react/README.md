# React 19 inside a drawable canvas

A small React 19 app whose whole UI is inside `<canvas content="drawable">` and painted with `drawElementImage` from the `paint` event: a controlled input, a keyed list (Add / Remove first / Reverse buttons, click a row to select it), a conditional second drawable (the red badge, drawn at (340, 300) while it is laid out at the origin), and a timer component that re-renders every 500 ms. `dist/hic-live-polyfill.iife.js` is loaded BEFORE the app bundle.

Files: `App.jsx` (the app), `main.jsx` (createRoot, or hydrateRoot when the container already holds server markup), `index.html`. `dist/hydrate.html` is generated by the build with `react-dom/server` and hydrates the same app. Shared data and CSS: `../shared/app-spec.js`.

## The pattern

- The canvas is wired by a **React 19 callback ref with a cleanup function** (`useCanvasPainter`), so a canvas that a conditional render re-creates is wired again and the old one is released.
- `paint` is listened to with `addEventListener`, which survives `uninstall()` / `install()`.
- Drawables are read from refs inside the paint handler (`badgeRef.current` is `null` while the badge is unmounted).
- `suppressHydrationWarning` on the `<canvas>`: the polyfill adds `data-hic-canvas` and `aria-owns` to the canvas before `hydrateRoot` runs (docs/guides/FRAMEWORKS.md, section 4). Every top-level drawable has an explicit `id`, otherwise the polyfill generates one and React reports that too.

## Run it

```sh
npm run build                                   # dist/ (the polyfill)
(cd test/frameworks && npm install)             # framework deps live there, never in the root package
node test/frameworks/build.mjs                  # builds examples/frameworks/*/dist/app.js
npm run demo                                    # then open http://127.0.0.1:8765/examples/frameworks/react/
```

`?tick=0` stops the timer, `?mode=ref` renders the plain-DOM twin used by the pixel oracle. Tested by `npm run test:frameworks` (headless Chrome 154, results in `.scratch/results/`); see [docs/guides/FRAMEWORKS.md](../../../docs/guides/FRAMEWORKS.md) for what was verified.
